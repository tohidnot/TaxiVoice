# TaxiVoice

Desktop audio/video editor (Electron). Transcribe with NVIDIA Parakeet TDT 0.6B v3, delete words, export a clean cut.

```bash
cd ~/Desktop/TaxiVoice
./start.sh
```

- Drop an audio or video file, or use **+**
- Click **×** on a word to cut it
- Chat: `remove fillers` or `delete like`
- **Export** writes a cleaned mp3 or mp4
